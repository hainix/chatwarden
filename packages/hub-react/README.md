# @chatwarden/hub-react

The moderator hub for Chatwarden, the open-source chat moderation kit for games: a React UI over the kit's staff HTTP API.

Status: pre-release, as-is, no support promise.

## Install

```sh
npm install @chatwarden/hub-react @chatwarden/core @chatwarden/http react react-dom
```

Node 22.13 or newer.

## Quick start

```ts
import { VERSION } from '@chatwarden/hub-react';

console.log(VERSION);
```
